# Progress

In-flight steps keep their log here, one file per step (`docs/progress/<step>.md`, for example the page session's
`page.md` and M9b's `m9b.md` on their branches). The folders here hold the capture images the tools write.
Finished logs are in [docs/archive/progress/](../archive/progress/README.md); where things stand now is in
[STATUS.md](../STATUS.md).
