`AUDIT.tsv` covers all product TypeScript/JavaScript and data-producing `tools/` jobs. This includes core generation/analysis/planning/forces/water, editor gesture geometry/brushes/freehand/select/features, workers and batch jobs. Renderer calls and pinned Three 0.186.1 camera/ray dependency calls are replaced too because picking can feed operations. The Vite plugin disables prebundling of Three and transforms it in dev/build; CI rejects a missing plugin and checks 1,512 actual camera/ray/pick/projection cases with native maths trapped. Three UUID/random helper definitions mint host inputs; they do not perform deterministic map computation. Only the three listed image-capture/renderer-timing CLI probes are excluded. The guard allows exact ECMAScript arithmetic helpers/constants. Its narrowly identified random calls mint recorded host inputs or audio/UI presentation; no random call is allowed in deterministic computation. Wall-clock work scheduling must persist completed stage counts (the determinism study's M9b worker fix is included). Equal comparator keys return zero.

Evaluated tool strings and callbacks use tools/portable-page.ts's portableEvaluate adapter, which binds the audited module inside the page. The source guard also inspects embedded strings/powers and rejects unknown external imports, indirect eval and unaudited Wasm bindings. Fifty-eight actual script/adapter checks match across all browsers with native maths trapped; this certifies their numeric selections and transfer functions, not PNG/DOM/GPU bytes.

The shared module keeps determinism's fixed sin/cos/exp and ordered log/pow/hypot/atan/atan2, with tan/log2/tanh/asinh/asin/acos adapters and an exact remainder bridge. Rust remainder uses integer binary long division; JavaScript uses its specified remainder operator. It targets the finite map domain; do not substitute a general native libm. Square root uses correctly rounded Wasm `f64.sqrt`, or exact BigInt midpoint rounding when Wasm is blocked. The fallback never calls Math.sqrt. The gzip/zip/zlib adapter supplies explicit memory decisions, including ZIP directory entries, so pinned fflate 0.8.3 cannot execute its native logarithm heuristic. Dependency version changes require a new audit.

Apply `rust-adoption.patch` only to the exact study sources identified in `RESULTS.json`. This patch changes maths in those studies; it does not certify their wider implementation/adoption status. Keep their existing acceptance gates. Compile Rust 1.90.0 with strict floating point, native x86-64-v2 and target-feature=-fma. Audit source, optimized LLVM IR, assembly and unstripped Wasm function names/imports. The guard rejects libm (including statically linked Rust libm), transcendental LLVM intrinsics, FMA/fmuladd, floating frem, fused machine instructions and relaxed arithmetic flags. Re-run it for any compiler/target/flags change. Do not strip the Wasm before its audit.

## Reproduction and CI

Run from the repository root. `node investigation/portable-math/setup.mjs` installs the pinned private runtime under ignored local/. Existing matching dependencies may be selected with DGM_DEPS; DGM_THREE can select a read-only Three 0.186.1 package directory. Install its Playwright engines if missing. Source readbacks and all generated maps, archives, bundles, binaries, IR and large per-case records stay in local/.

First run snapshot.mjs, build.mjs, weather-revisions.mjs and weather-terms.mjs to reproduce both untouched Weather sources. For the investigation candidate: run audit.mjs, guard.mjs --adoption, guard-test.mjs, typecheck.mjs, math-check.mjs, compression-check.mjs, three-check.mjs, rust-sources.mjs, rust-math.mjs, guard-plants.mjs, rust-build.mjs, build.mjs, generation.mjs, curves.mjs, water.mjs --forced, fixtures.mjs, water.mjs --official, water.mjs --maps, water.mjs --weather, native-weather.mjs, gestures.mjs, embedded-check.mjs, carve.mjs, tools-check.mjs, and the commands in PROFILE_REPORT.md. Files ending in .mjs above live in investigation/portable-math/. `--reuse` retains the existing coordinator/helper pools for 20 map cases before retiring the pages; numeric kernels and comparison rules are unchanged. DGM_SIZE selects a CI size shard; an unsharded final proof must contain all 840 maps. `--resume` on generation/water only accepts matching bundle provenance, engines, inputs and thread counts.

DGM_OFFICIAL supplies the original 19 non-development .timber archives; DGM_INPUTS supplies the 19 archived official water models from water-speed. Neither private corpus belongs in git. DGM_STUDIES can select existing read-only Rust study checkouts. rust-sources.mjs snapshots them before applying any transformation. The copied parallel-water runtime is a verification harness; the product adoption patch does not adopt that runtime.

The adoption patch installs `.github/workflows/portable-math.yml` and routes the old determinism guard to the whole-source guard. CI typechecks/builds the actual product and audits minified worker/dependency chunks. The output guard permits only Comlink's exact 2^53 request-ID constant and the pinned, unreachable fflate memory fallback; host IDs and audio randomization remain input/presentation concerns checked in source. CI checks actual adopted product sources without overlays in three size shards (280 maps each): all 840 generation cases, golden contracts, operation geometry, Weather and seven helper counts, plus actual Rust studies present in that revision. Original official archives require separately provisioned private inputs. Python reference/oracle programs and historical study oracles remain independent comparison inputs; their native maths does not produce product operations. Every guard is demonstrated rejecting a planted native call. For example, `node investigation/portable-math/check-pins.mjs --suite generation` consumes the published pins for the declared experimental source/input profile; it fails on a changed byte or missing case. Other suites are water, fixtures, forces, carve, gestures, camera, forcing and embedded; run them separately. Re-pin the exact outputs listed in RESULTS.json; do not update unrelated speedup fixtures to mask a change.

Byte identity means ordered raw binary64 bits (including signed zero), typed arrays, object/Map/Set order, operation/checkpoint records and exact exported bytes. Only measured wall-clock durations are excluded. The measured target is Windows x64 with Chromium 145.0.7632.6, Firefox 146.0.1 and WebKit 26.0; other builds must run the gate before being certified.
