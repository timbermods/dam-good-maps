# Assets

Terrain and samples are generated by Dam Good Maps' MIT-licensed code.
All demo meshes, interface and effects are original code. Terrain swatches and moisture use
the repository's MIT-licensed product palette and soil rule. No Timberborn assets.
The standalone shell and capture runner adapt the repository's MIT-licensed Rift demo
from dev (`ab51e760`); the Deposit planner is new investigation code.

Sound loads existing repository recordings directly from investigation/juice-2/audio:

| Recording | Author | Repository licence evidence |
| --- | --- | --- |
| earth-bed.mp3 | Kenney | ../juice-2/SOUNDS.md, source K, CC0 |
| earth-b.mp3 | Kenney | ../juice-2/SOUNDS.md, source K, CC0 |
| waterfall.mp3 | Tom_Kaszuba | ../juice-2/SOUNDS.md, source W, CC0 |

Web Audio lowers pitch and filters the recordings; the waterfall loops softly with a fade
throughout growth. The built demo bundles these three files; no duplicated sound bank is committed.
