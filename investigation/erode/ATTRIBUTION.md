# Attribution

Nothing here comes from Timberborn's files. The land is our own generated maps (the editor's generator, the
design version 2 prototype and Craterize's investigation engine). Every texture is drawn by a shader (value noise,
cracks, cobbles), with the repository's own palette (`src/render3d/palette.ts`, `waterPalette.ts`). Trees, the
start and the rubble are simple shapes made in code.

## Sounds

Every recording is **CC0 1.0** ([legal text](https://creativecommons.org/publicdomain/zero/1.0/legalcode)),
checked on each sound's page on 27 September 2026. Credits are kept for traceability, not because attribution is
a condition. Each file is Freesound's public high-quality MP3 preview, shipped as downloaded (no edits; the
demo plays slices of it, pitched and filtered in Web Audio). They are previews, not the lossless originals.
