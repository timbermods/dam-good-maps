# Meander

> **Adopted into Carve, not a force of its own (Kyler, 2026-09-30, PLAN �20 D355).** Meander only works on an existing
> river, so on most of the map it does nothing. Its engine (oxbow lakes, a floodplain, cut banks and point bars) becomes
> Carve's **Maturity** option in More (Young, Mature, Auto): Young is today's Carve; Mature carves the river, then ages
> it with this engine. Carve used along an existing river matures it (Meander's own gesture).

Give an existing river centuries. Its bends swing downstream, cut banks retreat, and sediment
builds inside bars and a flatter valley floor. At high Power, a tight bend can become an oxbow.

From the repository root, on this branch:

```powershell
npm --prefix investigation/meander ci
npm --prefix investigation/meander run demo -- --port 5178
```

Open the printed localhost address. Choose a landscape and **Try this Meander**, or click its
river / drag along a stretch. The drawing band shows the river's width. Off-river gestures say why
they cannot act. The camera stays still; the wheel zooms.

**Power** sets the time passed. **Size** sets a click's reach along the river; Auto follows Power.
**More** holds Bends (Auto, Tight, Broad), and the shared **Floor** (Default 1, up to 22).
Floor remains a rule with Default, following the shared core. It has no Auto.

**Watch** shows the age increments four times slower. **Esc** cancels drawing or finishes playback.
**Undo / Ctrl Z** restores the complete map at any moment. **Try another** replaces the last result
with another seed. Hold **F** and drag to set Size; **{ / }** adjust Power. Numbers stay visible.

The three 128² specimens are generated by Dam Good Maps at base `9e14f189`:
River Valley seed 1, Canyon seed 9, and Canyon seed 5. Their existing land and sources are translated
up three levels, with water depths unchanged, giving Floor 1 room to act. No river is drawn into
the specimens. `samples.ts` records the complete generation spec in each compressed map.

Regenerate and check:

```powershell
npm --prefix investigation/meander run samples
npm --prefix investigation/meander run typecheck
npm --prefix investigation/meander run build
npm --prefix investigation/meander run check
npm --prefix investigation/meander run captures
```

Captures require the demo running at port 5178 and installed Microsoft Edge. Set `MEANDER_URL`
if Vite printed another address. Six 960×640 JPEGs and one 600px GIF are kept in `captures/`.
Extra frames, bundled runners, dependencies and builds stay ignored; bulk results belong in `local/`.
