# Sources

The terrain algorithms and effect pools come from this repository’s four investigations,
pinned in SOURCES.json. Their terrain formulas and seed arithmetic remain intact except for
the documented integration of volcanic rock into the current Carve. The original reports,
attributions and checks can be read directly at those commits.

This study uses the repository’s renderer, entity footprints, water simulation, generated
fixtures and bundled real-place data. It does not copy game code, workshop maps or reference
screenshots. The captured maps are this study’s own fixtures. Three.js is MIT licensed and
pinned to the repository’s 0.186.0 version; other dependencies retain their package licenses.
