# Dam Good Maps Companion

Play the map you just saved in Dam Good Maps without clicking through the menus. An unofficial mod, not made by Mechanistry.

## Install

- **Steam Workshop:** subscribe to Dam Good Maps Companion. It is not listed yet.
- **By hand:** copy the `DGMCompanion` folder into `Documents\Timberborn\Mods`.

Start Timberborn and turn the mod on in the mod manager.

## Play the latest map

1. In Dam Good Maps, save the map to Timberborn.
2. In the main menu, click **Play latest Dam Good Maps map**. The map's name and size are under it.

A new game starts on that map with the faction and difficulty of your last new game. Before you have played one, it uses the first faction and the default difficulty. The game asks you to name the settlement.

The entry is hidden when your Maps folder has no map from Dam Good Maps.

## Reload after saving again

Changed the map and saved it again? In the game, press **Ctrl+Shift+R** (**Cmd+Shift+R** on a Mac). Dam Good Maps saves a repeat as a new file, like `name-2`; the mod finds the newest save of the map you are playing. Confirm **Reload** to start it as a new game. Progress in the current game is lost.

## Settings

The mod keeps its own file, `Documents\Timberborn\DGMCompanion\settings.json`, and never touches the game's settings.

- `reloadKey`: the reload key, for example `"Ctrl+Shift+R"` or `"F9"`.
- `mapsFolder`: read maps from here instead of `Documents\Timberborn\Maps`.

## Remove

Turn the mod off in the mod manager, then delete the `DGMCompanion` folder from `Mods`. To clear what it remembered, delete `Documents\Timberborn\DGMCompanion`.
